# Rule: Always Show Server Link After Execution

After **every code change, fix, or update** in this workspace, always end your response with the live server link so the user can immediately preview the changes.

## Format

End every response that involves a code change with:

---
🌐 **Preview changes:** [http://localhost:4010](http://localhost:4010)

## Notes
- The dev server runs at `http://localhost:4010`
- This applies to ALL coding work: bug fixes, UI changes, new features, refactors, etc.
- Do NOT skip this even for small one-line fixes
